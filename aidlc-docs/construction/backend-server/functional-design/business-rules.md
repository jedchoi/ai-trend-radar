# Business Rules — backend-server

| ID | 규칙 | Story · AC |
| --- | --- | --- |
| BR-S01 | 업로드는 `Authorization: Bearer <token>` 의 SHA-256 이 설정값 `INGEST_TOKEN_SHA256` 과 같을 때만 허용. 헤더 없음 · 불일치 → 401, 설정값 없음 → 503 (닫힌 실패). 비교는 상수 시간 | AC-19-1 |
| BR-S02 | 일일 업로드는 한 트랜잭션: 그 날짜의 digest · papers · keywords · fts · hub 를 지우고 새로 넣는다. 중간 오류 시 전부 되돌린다 | AC-19-2, NFR-03 |
| BR-S03 | 다른 날짜에 이미 있는 논문 id 가 오면 새 날짜로 옮긴다 (논문은 한 날짜에만 존재) | AC-19-2 |
| BR-S04 | 업로드 형식 위반 (필수 필드 누락, 범위 · 길이 초과, 모르는 topic) → 422, 저장 0건. 오류 응답에 입력 값은 넣지 않는다 | AC-19-3 |
| BR-S05 | 날짜 목록은 최신순, `limit` 1~90 (기본 30) | AC-01-3 |
| BR-S06 | 일일 요약의 논문 순서: 주목 논문 먼저, 그 안에서 추천 수 내림차순, 같으면 id 오름차순 | AC-01-2 |
| BR-S07 | Hub `is_new`: 전날 (달력 기준 하루 전) 같은 kind 목록에 없던 항목. 전날 Hub 데이터가 아예 없으면 `false` | AC-03-2 |
| BR-S08 | Hub `streak_days`: 그날까지 하루도 빠짐없이 같은 kind 목록에 있던 연속 일수 (그날 포함, 최소 1) | US-03, AC-09-5 |
| BR-S09 | 관련 이전 논문: 같은 정규화 키워드를 1개 이상 공유하고 날짜가 같거나 이전이며 자기 자신이 아닌 논문. 날짜 내림차순 → 공유 키워드 수 내림차순 → 추천 수 내림차순, 최대 5편 | AC-07-1 |
| BR-S10 | 검색어는 공백으로 나눈 단어 (최대 8개, 각 1~40자) 를 모두 포함 (AND, 접두어 일치) 하는 논문. 따옴표 등 특수 문자는 제거해 FTS 문법으로 해석되지 않게 한다. 검색어가 비면 필터만 적용 | AC-12-1 |
| BR-S11 | 검색 결과는 날짜 내림차순 → 추천 수 내림차순, `limit` 1~50 (기본 20), `offset` 0~1000, `total` 은 필터 적용 전체 건수 | AC-12-1, AC-12-2 |
| BR-S12 | 주 = ISO 주 (월~일), 날짜는 digest 날짜 기준. 월 = 달력 월 | AC-09-1 |
| BR-S13 | 주제 통계: 기간 안 주제별 편수, 직전 기간 편수, `delta = count - prev_count`. 편수 내림차순, 0편 주제는 직전에 있었을 때만 포함 | AC-09-2 |
| BR-S14 | 급상승 키워드: 기간 편수 `count` 와 직전 4개 기간 평균 `baseline` 비교. `ratio = count / max(baseline, 0.5)`. `count >= 3` 이고 `ratio >= 2.0` 인 것, ratio 내림차순 → count 내림차순, 최대 10개 | AC-09-3 |
| BR-S15 | `baseline_ready`: 가장 이른 digest 날짜가 직전 4개 기간의 첫날 이전이거나 같을 때 `true`. `false` 면 급상승 키워드는 빈 목록 | AC-09-3 |
| BR-S16 | 화제 논문: 기간 안 추천 수 상위 5편 (같으면 날짜 내림차순) | AC-09-4 |
| BR-S17 | Hub 신규 진입: 기간 안에서 처음 등장했고 기간 이전에는 없던 항목, `days` = 기간 안 등장 일수. 최대 10개, days 내림차순 | AC-09-5 |
| BR-S18 | Hub 체류: 기간 마지막 Hub 날짜의 항목과 그 `streak_days`, streak 내림차순 최대 10개 | AC-09-5 |
| BR-S19 | 시계열: 최근 `weeks` 개 ISO 주 (1~26, 기본 12, 최신 digest 의 주까지) 의 주제별 편수, 빈 주는 0 | AC-10-1 |
| BR-S20 | `latest` 주 · 월 = 데이터가 있는 가장 최근 기간. 데이터 없음 → 404 | AC-09-1 |
| BR-S21 | 리포트 업로드는 BR-S01 인증 후 (period, key) 단위로 덮어쓰기. narrative 1~3000자 | AC-20-1 |
| BR-S22 | 없는 날짜 · 논문 · 형식이 틀린 경로 값 → 404 또는 422, 본문은 `{"error": "<code>"}` 형식 | AC-14-2 |
