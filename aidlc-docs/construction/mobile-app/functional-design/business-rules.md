# Business Rules — mobile-app

| ID | 규칙 | Story · AC |
| --- | --- | --- |
| BR-A01 | 앱 시작 시 `digests/latest` 와 `digests?limit=30` 을 불러온다. 날짜 칩을 누르면 `digests/{date}` | AC-01-1, AC-01-3 |
| BR-A02 | 주목 논문 = `featured` 가 true 인 논문 (서버 정렬 순서 유지). 카드에 제목 · 주제 · 한 줄 요약 · 추천 수 · 코드 공개 (GitHub 주소 있음) 표시 | AC-01-2 |
| BR-A03 | 주제 칩 = "전체" + 그날 논문에 등장한 주제 (주제 순서대로). 고르면 전체 목록에서 그 주제만 | AC-02-1 |
| BR-A04 | Hub 영역은 모델 · 데이터셋 · Spaces 탭, 항목에 순위 · 이름 · 좋아요, `is_new` 면 "신규", `streak_days ≥ 3` 이면 "N일째". 누르면 `url` 을 외부 브라우저로 연다 | AC-03-1 ~ AC-03-3 |
| BR-A05 | 관심 키워드 매칭: 논문의 제목 · 키워드 · 한 줄 요약 · 주제 이름 (한국어) 중 하나에 등록 키워드가 대소문자 무시 부분 일치하면 매칭. 매칭 논문은 각 목록 안에서 위로 (원래 순서 유지), "관심" 표시와 맞은 키워드 | AC-04-2 |
| BR-A06 | 관심 키워드는 1~30자, 최대 20개, 중복 (대소문자 무시) 은 추가하지 않는다 | AC-04-1 |
| BR-A07 | 상세 화면: `detail` 이 있으면 4항목, 없으면 한 줄 요약 + 초록 + "초록 기반" 표시. 용어 카드, 링크 (원문 `hf_url` 항상, GitHub · 프로젝트 페이지 있으면), 관련 이전 논문 | AC-05-1 ~ AC-07-2 |
| BR-A08 | AI 에게 묻기 글: 제목 · 링크 (hf_url, GitHub) · 한 줄 요약 · (있으면) 상세 4항목 + 질문 틀 3개 ("핵심 아이디어를 쉽게", "우리 업무에 적용하려면", "비슷한 기존 방법과 비교"). 클립보드 복사 후 고른 AI 주소 (Claude `https://claude.ai/new`, ChatGPT `https://chatgpt.com/`, Gemini `https://gemini.google.com/app`) 를 연다 | AC-08-1, AC-08-2 |
| BR-A09 | 트렌드: 주간 · 월간 전환, 기간 칩 (`trends/periods`), 리포트 문장, 주제 막대 (편수 + 전주 대비 증감), 12주 선 차트 (`trends/series`, 상위 5개 주제), 급상승 키워드 (`baseline_ready=false` 면 "데이터 수집 중"), 화제 논문, Hub 신규 · 체류 | AC-09-1 ~ AC-11-1 |
| BR-A10 | 검색: 검색어 (300자 이하), 주제, 기간 (7일 · 30일 · 전체), 주목만. 결과 20개씩, 더 보기. 결과 0개면 "결과 없음" | AC-12-1 ~ AC-12-3 |
| BR-A11 | 보관함: 북마크 토글, 상태 4종 (읽을 것 · 시험 중 · 적용함 · 보류, 새로 저장하면 읽을 것), 메모 (1000자), 상태별 필터, 저장 순서는 최근 저장 먼저. 기기 저장 | AC-13-1 ~ AC-13-3 |
| BR-A12 | 오프라인: 서버 응답을 받으면 경로별로 저장. 실패하면 저장본을 "오프라인" 표시와 보여주고, 저장본도 없으면 오류 안내 + 다시 시도 | AC-14-1, AC-14-2 |
| BR-A13 | 서버 주소: `http://` 또는 `https://` 로 시작하는 주소만 저장 (끝의 `/` 제거). 비어 있으면 네트워크를 쓰지 않고 "설정에서 서버 주소를 입력하세요" 안내 (2026-11-17 변경: 데모 데이터 제거, 사용자 요청). 빌드 기본값은 `--dart-define=RADAR_SERVER_URL` | AC-15-1, AC-15-2 |
