# User Stories

> 구성: 사용자 여정 순서 (매일 훑기 → 깊이 보기 → 흐름 보기 → 찾기 · 쌓기 · 적용 → 운영). AC 는 확인 가능한 조건 · 결과로 쓴다.

## Epic A. 매일 훑기 (P1)

### US-01 오늘의 요약 보기 (FR-14)
P1 로서, 앱을 열면 가장 최근 날짜의 세 줄 요약과 주목 논문을 보고 싶다. 5분 안에 그날 흐름을 알기 위해서다.
- AC-01-1: 앱을 열면 서버의 최신 날짜 일일 요약이 표시되고, 맨 위에 세 줄 요약이 있다
- AC-01-2: 주목 논문 (최대 5편) 이 카드로 먼저 나오고, 카드에 제목 · 주제 · 한 줄 요약 · 추천 수 · 코드 공개 표시가 있다
- AC-01-3: 날짜 칩을 누르면 그 날짜의 요약으로 바뀐다 (최근 30일)

### US-02 주제로 걸러 보기 (FR-14)
P1 로서, 주제 칩으로 전체 논문 목록을 거르고 싶다.
- AC-02-1: 주제 칩 (전체 + 그날 등장한 주제) 을 누르면 그 주제 논문만 남는다
- AC-02-2: 각 논문 행에 제목 · 한 줄 요약 · 주제 · 추천 수가 있다

### US-03 Hub 트렌드 보기 (FR-14)
P1 로서, 오늘 뜨는 모델 · 데이터셋 · Spaces 를 보고 싶다.
- AC-03-1: 모델 · 데이터셋 · Spaces 가 각각 순위 · 이름 · 좋아요 수와 함께 나온다
- AC-03-2: 전날 목록에 없던 항목에 "신규" 표시가 있다
- AC-03-3: 항목을 누르면 Hugging Face 페이지가 열린다

### US-04 관심 키워드 우선 보기 (FR-19, FR-22)
P1 로서, 내 업무 키워드를 등록해 관련 논문을 먼저 보고 싶다.
- AC-04-1: 설정에서 키워드를 추가 · 삭제할 수 있고 앱을 다시 열어도 유지된다
- AC-04-2: 제목 · 키워드 · 한 줄 요약에 등록 키워드가 있는 논문은 목록 위로 오고 "관심" 표시가 붙는다 (대소문자 무시)

## Epic B. 깊이 보기 · 적용 (P1)

### US-05 논문 요약 보기 (FR-15)
P1 로서, 논문 한 편의 요약을 한국어로 읽고 실무 적용 여부를 판단하고 싶다.
- AC-05-1: 주목 논문은 무엇을 했나 · 새로운 점 · 왜 중요한가 · 실무 적용 4항목이 나온다
- AC-05-2: 주목 논문이 아니면 한 줄 요약과 원문 초록이 나오고 "초록 기반" 표시가 있다
- AC-05-3: 용어 카드가 있으면 용어와 1~2문장 설명이 나온다

### US-06 바로 써보기 링크 (FR-15)
P1 로서, 논문에서 코드 · 모델 · 데모로 바로 가고 싶다.
- AC-06-1: 원문 (Hugging Face 논문 페이지) 링크가 항상 있다
- AC-06-2: GitHub 저장소 · 프로젝트 페이지가 있으면 링크와 스타 수가 나온다

### US-07 관련 이전 논문 (FR-11, FR-15)
P1 로서, 같은 키워드의 지난 논문을 이어서 보고 싶다.
- AC-07-1: 상세 화면 아래에 같은 키워드를 공유하는 이전 논문이 최신순 최대 5편 나온다
- AC-07-2: 항목을 누르면 그 논문 상세로 이동한다

### US-08 AI 에게 이어서 묻기 (FR-20)
P1 로서, 논문을 내가 쓰는 AI 에게 넘겨 더 물어보고 싶다.
- AC-08-1: "AI 에게 묻기" 를 누르면 제목 · 요약 · 링크 · 질문 틀이 담긴 글이 클립보드에 복사된다
- AC-08-2: 설정에서 고른 AI (Claude · ChatGPT · Gemini) 의 웹 주소가 열린다

## Epic C. 흐름 보기 (P1)

### US-09 주간 트렌드 보기 (FR-13, FR-16)
P1 로서, 이번 주 어떤 분야가 뜨는지 근거 숫자와 함께 보고 싶다.
- AC-09-1: 주 선택 (최근 12주) 과 그 주의 리포트 문장이 나온다. 문장이 없으면 통계만 나온다
- AC-09-2: 주제별 편수와 전주 대비 증감이 막대로 나온다
- AC-09-3: 급상승 키워드가 직전 4주 평균 대비 배수와 함께 나온다 (4주치 데이터가 쌓이기 전에는 "데이터 수집 중" 안내)
- AC-09-4: 그 주의 추천 수 상위 논문 5편이 나오고 누르면 상세로 간다
- AC-09-5: Hub 신규 진입 항목과 연속 체류 일수가 나온다

### US-10 주제별 추이 보기 (FR-13, FR-16)
P1 로서, 주제별 편수의 몇 주 추이를 차트로 보고 싶다.
- AC-10-1: 최근 12주 주제별 주간 편수가 선 차트로 나오고 범례가 있다

### US-11 월간 리포트 (FR-08, FR-16)
P1 로서, 한 달 흐름을 요약해서 보고 싶다.
- AC-11-1: 월 리포트가 있으면 트렌드 화면에서 주간 · 월간을 바꿔 볼 수 있다

## Epic D. 찾기 · 쌓기 (P1)

### US-12 논문 검색 (FR-12, FR-17)
P1 로서, 지난 논문을 검색어 · 주제 · 기간으로 찾고 싶다.
- AC-12-1: 검색어를 넣으면 제목 · 요약 · 키워드에 맞는 논문이 최신순으로 나온다
- AC-12-2: 주제 · 기간 (최근 7일 · 30일 · 전체) · 주목만 필터가 결과에 적용된다
- AC-12-3: 결과가 없으면 "결과 없음" 안내가 나온다

### US-13 보관함 (FR-18)
P1 로서, 논문을 저장하고 적용 상태와 메모를 관리하고 싶다.
- AC-13-1: 상세 화면에서 북마크하면 보관함에 나오고, 앱을 다시 열어도 유지된다
- AC-13-2: 상태를 읽을 것 · 시험 중 · 적용함 · 보류 중 하나로 바꾸고, 상태별로 걸러 볼 수 있다
- AC-13-3: 메모를 쓰고 고칠 수 있다

### US-14 오프라인 열기 (FR-21)
P1 로서, 네트워크가 없어도 마지막으로 본 요약을 열고 싶다.
- AC-14-1: 서버에 닿지 않으면 마지막으로 받은 일일 요약 · 트렌드가 "오프라인" 표시와 함께 나온다
- AC-14-2: 받은 적이 없으면 서버 주소 확인 안내와 다시 시도 버튼이 나온다

### US-15 서버 주소 설정 (FR-22)
P1 로서, 내 서버 주소를 앱에서 바꾸고 싶다.
- AC-15-1: 설정에서 주소를 저장하면 그 주소로 다시 불러온다
- AC-15-2: `https://` 또는 `http://` 로 시작하지 않는 주소는 저장하지 않고 안내한다

## Epic E. 운영 (P2)

### US-16 매일 자동 수집 · 분석 (FR-01 ~ FR-03, FR-09)
P2 로서, PC 가 매일 정해진 시각에 수집 · 분석을 끝내 주길 바란다.
- AC-16-1: `radar daily` 한 번으로 수집 → 선별 → 분석 → 검사 → 업로드가 끝난다
- AC-16-2: 실행 기록 파일에 날짜 · 건수 · 제공자 · 소요 시간 · 결과 (성공 · 실패 단계) 한 줄이 추가된다
- AC-16-3: 대상 날짜에 논문이 0편 (주말 등) 이면 Hub 트렌드만 올리고 성공으로 기록한다

### US-17 AI 제공자 바꾸기 (FR-04, FR-05, NFR-01)
P2 로서, 설정 한 줄로 AI 를 바꾸거나 AI 없이 돌리고 싶다.
- AC-17-1: `provider = "none"` 이면 API 키 없이 전체 흐름이 끝나고, 한 줄 요약은 Hugging Face AI 요약, 주제는 키워드 규칙으로 정해진다
- AC-17-2: AI 응답이 스키마에 어긋나면 1회 다시 요청하고, 또 어긋나면 그 논문은 `none` 결과로 대체되며 기록에 남는다
- AC-17-3: 키가 필요한 제공자인데 키가 없으면 실행 전에 무엇이 없는지 알려주고 멈춘다

### US-18 빠진 날 채우기 (FR-07)
P2 로서, PC 가 꺼져 있던 날도 나중에 채워지길 바란다.
- AC-18-1: 마지막 성공일 다음 날부터 어제까지 (최대 7일) 순서대로 처리한다
- AC-18-2: `--date YYYY-MM-DD` 로 특정 날짜만 다시 돌릴 수 있다

### US-19 안전한 업로드 (FR-06, FR-10, NFR-03, NFR-04)
P2 로서, 나만 서버에 올릴 수 있고 실패해도 기존 데이터가 망가지지 않길 바란다.
- AC-19-1: 토큰이 없거나 틀리면 업로드는 401 이고 아무것도 저장되지 않는다
- AC-19-2: 같은 날짜를 다시 올리면 그 날짜 데이터가 통째로 바뀐다 (중복 없음)
- AC-19-3: 업로드 내용이 형식에 어긋나면 422 이고 아무것도 저장되지 않는다

### US-20 주간 · 월간 리포트 작성 (FR-08)
P2 로서, 리포트 문장이 자동으로 붙길 바란다.
- AC-20-1: 월요일 실행에서 지난주 통계를 받아 해석 문장을 올린다. 매월 1일에는 지난달도 같은 방식
- AC-20-2: `none` 이면 통계에서 만든 규칙 문장 (상위 주제 · 급상승 키워드) 을 올린다

## Epic F. 2주기: 바로 쓰기 · 뉴스 · 원문 (P1)

### US-21 설치하면 바로 보기 (FR-29, FR-31)
- AC-21-1: `tool/radar-up.sh` 로 설치한 앱은 설정 없이 첫 화면에 서버 데이터를 보여준다
- AC-21-2: 설정의 서버 주소를 바꾸면 그 서버에서 다시 받는다

### US-22 Hugging Face 뉴스 읽기 (FR-25, FR-27, FR-30)
- AC-22-1: 뉴스 탭에 최신순으로 제목 · 한국어 요약 · 출처 조직 · 날짜가 보이고, 끝까지 내리면 다음 페이지를 불러온다
- AC-22-2: 뉴스 상세에 한국어 요약 · 핵심 · 키워드와 원문 본문 전체, 원문 링크가 있다
- AC-22-3: 검색어로 뉴스를 찾는다

### US-23 원문 확인 (FR-26, FR-27)
- AC-23-1: 논문 상세에서 초록 원문을 펼쳐 보고, 주목 논문은 본문 원문을 읽는다
- AC-23-2: 원문이 없으면 arXiv · Hugging Face 링크를 보여준다

### US-24 매일 아침 자동 갱신 (FR-28)
- AC-24-1: 매일 06:00 에 수집 · 분석 · 업로드가 실행되고 실행 기록이 남는다
- AC-24-2: 월요일에는 주간, 1일에는 월간 리포트가 갱신된다

### US-25 Docker 서버 (FR-23, FR-24)
- AC-25-1: 한 명령으로 Postgres 와 API 가 뜨고, 다시 띄워도 데이터가 남는다
- AC-25-2: 이미 있는 Postgres 주소를 주면 그 DB 를 쓴다

### US-26 편하게 읽기 (FR-30)
- AC-26-1: 모든 목록은 당겨서 새로고침된다
- AC-26-2: 읽은 논문 · 뉴스는 흐리게 표시된다
- AC-26-3: 글자 크기를 설정에서 바꾼다
- AC-26-4: 뉴스도 보관함에 담고 공유 (링크 복사) 한다

### US-27 다른 AI 로 이어가기 (NFR-12)
- AC-27-1: handoff.md 에 현재 상태 · 실행 방법 · 남은 일 · 결정 이유가 있다

## Epic G. 3주기: 한국어 · 영어 (P1)

### US-28 언어 전환 (FR-32, FR-33)
- AC-28-1: 오늘 화면 위쪽 언어 버튼 (한 / EN) 을 누르면 메뉴 · 버튼 · 내용이 영어로 바뀌고, 다시 누르면 한국어로 돌아온다
- AC-28-2: 앱을 다시 열어도 고른 언어가 유지된다
- AC-28-3: 번역이 아직 없는 항목은 원래 언어로 보이고 "번역 준비 중" 표시가 붙는다

### US-29 원문까지 내 언어로 (FR-34)
- AC-29-1: 한국어에서 논문 제목, 뉴스 제목 · 본문이 한국어로 보이고, 논문 초록 · 본문은 영어 원문 그대로 보인다 (2026-11-18 개정)
- AC-29-2: 영어에서 요약 · 핵심 · 용어 · 세 줄 · 리포트가 영어로 보인다

### US-30 미리 번역해 두기 (FR-35, FR-36, NFR-13, NFR-14)
- AC-30-1: 매일 실행 끝에 새 내용이 번역되어 서버에 올라간다 (짧은 항목 먼저, 최근 날부터)
- AC-30-2: `tool/radar-daily.sh --translate 90` 으로 지난 데이터를 채우고, 끊겨도 이어서 한다
- AC-30-3: 원본 요약이 바뀌면 다시 번역한다

### US-31 한국어로 검색 (FR-37)
- AC-31-1: 영어 논문 · 뉴스를 번역된 한국어 낱말로 찾는다
