# Personas

## P1. 재혁 — AI 실무자 (앱 사용자)

- AI 를 현업에 적용하는 개발자. 출퇴근 · 쉬는 시간에 휴대폰으로 하루 5분 훑어본다
- 목표: 새 흐름을 놓치지 않기, 필요할 때 지난 논문을 다시 찾기, 쓸 만한 기술을 업무에 시험하기
- 불편: 논문이 하루 20편 이상이라 다 볼 수 없음, 영어 초록만으로는 실무 적용 여부를 판단하기 어려움
- 관련 요구: FR-14 ~ FR-22

## P2. 재혁 — 파이프라인 운영자 (PC 주인)

- 같은 사람이 자기 PC 에서 파이프라인을 돌리고 서버를 관리한다
- 목표: 손대지 않아도 매일 돌고, 실패하면 이유를 바로 알고, AI 제공자를 마음대로 바꾸기
- 관련 요구: FR-01 ~ FR-13, NFR-01, NFR-03 ~ NFR-05
